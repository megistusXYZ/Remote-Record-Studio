# Contributors

Vessel exists because people decided to spend their time on it. Thank you.

This file is a hand-curated list of people who have contributed code,
documentation, design, security research, or other meaningful work to
Vessel. The authoritative record of code authorship is the project's
git history; this list is a friendlier, human-readable version.

## How this list is maintained

- **New contributors are added when their first PR merges.** If you opened
  a PR and don't see your name here within a release, please poke us
  (or open a PR adding yourself).
- **Order is alphabetical by display name** within each section, not by
  contribution size or seniority. Everyone here matters.
- **Pseudonyms and handles are welcome.** Use whatever name you'd like to
  be known by. If you'd prefer not to be listed at all, just say so —
  we'll honor that.
- **Sign-offs (DCO) are tracked in commits, not here.** This file is
  about credit; contribution rights are governed by
  [`CONTRIBUTING.md`](./CONTRIBUTING.md) and [`LICENSE`](./LICENSE).
