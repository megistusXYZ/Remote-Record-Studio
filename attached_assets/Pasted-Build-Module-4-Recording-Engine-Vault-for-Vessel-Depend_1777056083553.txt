Depends on Modules 0–3.

=== RECORDING ENGINE (src/lib/recorder.ts + src/lib/blossom.ts) ===
(Same technical implementation as before, but with user-friendly event system)

ChunkedRecorder emits these user-friendly events (not technical ones):
  'recording-started'
  'chunk-saved-locally' (not "chunk 7 written to IndexedDB")
  'chunk-synced' (not "chunk uploaded to Blossom: sha256=abc")
  'chunk-sync-failed' (not "BUD-02 upload error 413")
  'recording-complete'
  'sync-complete'

BlossomUploadQueue exposes:
  progress: { synced: number, total: number, percent: number }
  status: 'idle' | 'syncing' | 'complete' | 'partial-failure'

=== SESSION COMPLETE / DELIVERY SCREEN ===
(src/components/studio/SessionComplete.tsx)

This is the "money shot" — the moment users fall in love with the product.

Full-screen overlay, shown after Stop + upload completion.

PHASE 1 — Syncing (while uploads run):
  Centered card, generous padding.
  Animated icon: a subtle waveform animation or reel spinning icon (SVG, accent color)
  Heading: "Saving your session..."
  Subtext: "We're packaging your tracks. This usually takes under a minute."

  Progress section — one row per participant:
  [Avatar] [Name]           [••••••••••] 100%  ✓ Saved
  [Avatar] [Guest Name]     [•••••••○○○]  72%  Syncing...

  Each row: progress bar (thin, accent color fill on bg-elevated), percentage, status icon
  Rows animate in staggered (framer-motion)

PHASE 2 — Complete (all uploads done):
  Transition: confetti burst (canvas, subtle — 1.5 seconds, then fades)
  Large animated checkmark (SVG stroke animation, accent color)
  
  Heading (Syne): "Session complete."
  Subtext: "Your recordings are ready. Each track is saved separately for studio-quality editing."
  
  Track download cards — one per participant:
  ┌──────────────────────────────────────────────────────┐
  │  [Avatar] [Name]'s Track                             │
  │  Video + Audio  •  43 min  •  2.1 GB                │
  │  [↓ Download Track]  [Copy File Link]               │
  └──────────────────────────────────────────────────────┘
  
  Bottom CTAs:
  [View in My Vault →]  (primary)
  [Start New Session]   (ghost)

GUEST EXPERIENCE — slightly different:
  After session complete, guest sees a special "Thank you" screen:
  "Thanks for recording with [Host Name]!"
  "[Host Name] will receive your track. Nothing to do on your end."
  Small text: "Want to keep your own copy?" + [Download Your Track] button
  (optional — some guests won't care)

=== THE VAULT (src/components/vault/VaultScreen.tsx) ===

This is the recordings library. Accessible from the lobby as "My Vault".

LAYOUT: Standard content page with sidebar nav.

SIDEBAR:
  - "My Vault" (active) with session count badge
  - "Shared with Me" (recordings from sessions where user was a guest)
  - "Settings" (gear icon)

MAIN CONTENT:

Header: "My Vault"  [Search sessions...] [Filter ▾]

Sessions list — each session as a card:

┌──────────────────────────────────────────────────────────────────┐
│  [Green dot] Session with Sarah Chen          Oct 14 • 43 min    │
│                                                                   │
│  [▶ Preview]  Sarah Chen  Emma Rivera  You                       │

│                                                                   │

  "Nothing in your vault yet"
  "Start a recording session to see your tracks here."
  [Start a Session →] button

=== SETTINGS SCREEN (src/components/vault/SettingsScreen.tsx) ===

Clean settings page. Two sections visible to all users:

GENERAL:
  - Display Name (editable input + Save button)
  - Avatar Color (color picker for their initials circle)
  - Default Invite Message (pre-fill for sharing)

ADVANCED (collapsed by default, "Show advanced settings" toggle):
  - Storage Location: "Where your files are saved"
    Input showing current Blossom server URL, editable
    Helper: "Your recordings are saved to a storage server you control.
             The default server is provided for free."
    (Never say "Blossom" — say "your storage server")
  - Live Preview Relay: input for MoQ relay URL
    Helper: "Powers the live video preview during recording."
    (Never say "MoQ" or "QUIC" — say "live preview relay")
  - Export Your Identity:
    Button: "Export backup key"
    Explains: "This key is your account. Keep it somewhere safe — it lets you
               restore your studio on any device." Then shows the nsec.
  - Danger Zone:
    "Clear local data" (clears IndexedDB + cached chunks)
    "Delete account" (just clears localStorage — explain this is just local data)
