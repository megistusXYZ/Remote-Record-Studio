Build Module 2: Lobby & Session Management for Vessel.
Depends on Modules 0 and 1.

User-facing language rules for this module:
  "session" → "studio session" or just "session"
  "Nostr event" → never mentioned
  "relay URL" → never mentioned  
  "pubkey" → "your studio ID" only in Settings
  "Blossom server" → "your vault" or "storage"

=== SESSION LOGIC (src/lib/session.ts) ===
(Same Nostr internals as before, but wrapped with user-friendly abstractions)

createSession(identity, settings):
  - Publishes Kind 30078 with Blossom URL + MoQ relay URL in tags
  - Returns { sessionId, inviteUrl }
  - inviteUrl: https://<domain>/?session=<sessionId>&host=<pubkey>
  (The pubkey in the URL is opaque to the user — they just see the link)

joinSession(sessionId, hostPubkey, pool):
  - Subscribes to the host's session event
  - Returns session config

=== LOBBY SCREEN (src/components/lobby/LobbyScreen.tsx) ===

This is the home screen for logged-in users. Three states:

STATE A — No active session (default):
  Layout: Centered, two-column on desktop, single on mobile.

  Left column:
    Greeting: "Good [morning/afternoon], [Name]." (Syne, large)
    Subtext: "Ready to record something great?"
    
    Big primary card — "New Session":
      Icon: large microphone SVG (accent color)
      Title: "Start a new studio session"
      Body: "Create a private room, invite your guests, and record in studio quality."
      CTA button: "Create Session →" (full-width, primary)

    Smaller secondary card — "Join a Session":
      Title: "Have an invite link?"
      Input: paste invite URL or session code
      Button: "Join →"

  Right column (or below on mobile):
    "Recent Sessions" list (from Vault, Module 5)
    If empty: illustration + "Your recordings will appear here"

STATE B — Session created (host waiting for guests):
  The screen transforms into a "waiting room" feel.

  Top: Session invite area (Card, accent border glow):
    "Share this link to invite guests:"
    Link displayed in monospace, truncated, with [Copy Link] and [QR Code] buttons
    QR code modal (qrcode.react) with the invite URL, large, centered
    
  Center: Participants list
    Header: "In the room" with a count badge
    Host row: Avatar + name + "You (Host)" badge + green status dot
    Guest rows as they join: Avatar + name + status dot (amber while joining, green when ready)
    Each row fades in with a subtle slide animation as participants join
    
  Below participants:
    "Waiting for guests..." (if no guests yet) — pulsing text
    OR "Everyone's here — let's go!" (if guests present)

  Bottom: Two buttons
    [Start Recording →] (primary, disabled if no guests but can be clicked by host alone)
    [Cancel Session] (ghost, danger color on hover)

STATE C — Active recording in progress → transitions to Studio (Module 3)
