Build Module 0: Landing Page and Design System for Vessel.

This is the most important module for user trust. Make it feel like a funded startup, not a demo.

=== PART A: Install & Configure ===

1. Initialize Vite + React + TypeScript project.
2. Install packages:
   npm install tailwindcss @tailwindcss/vite
   npm install applesauce-core applesauce-react applesauce-relay applesauce-signers
   npm install nostr-tools
   npm install idb @noble/hashes
   npm install zustand
   npm install framer-motion
   npm install qrcode.react
   npm install jszip

3. Configure Tailwind with custom theme in tailwind.config.ts:
   Extend with all CSS variables from the design system above.
   The custom colors should be accessible as: bg-base, bg-surface, text-primary, accent, etc.

4. Create src/index.css with:
   - Google Fonts import: Syne (700, 800), DM Sans (400, 500), JetBrains Mono (400)
   - All CSS variables from the design system
   - Global resets: box-sizing border-box, smooth scrolling, custom scrollbar (2px, accent color)
   - Body: bg-base color, text-primary, font-family DM Sans

=== PART B: Design System Primitives (src/components/ui/) ===

Create these components. Each is self-contained with its own variants:

Button.tsx:
  - Variants: 'primary' (accent bg, white text, pill), 'ghost' (transparent, accent border),
    'danger' (red), 'muted' (surface bg)
  - Sizes: 'sm', 'md' (default), 'lg'
  - States: loading (spinner replaces text), disabled (opacity 40%)
  - Micro-interaction: scale(0.97) on active, scale(1.02) on hover for primary
  - Usage: <Button variant="primary" size="lg" loading={isLoading}>Start Recording</Button>

Input.tsx:
  - Dark bg-surface background, border-strong border, accent focus ring
  - Label above, optional helper text below, error state (red border + message)
  - Sizes: 'sm', 'md'

Card.tsx:
  - bg-surface, border, rounded-2xl, optional hover state (bg-elevated, scale 1.01)
  - Variants: 'default', 'interactive' (hoverable), 'ghost' (no bg)

Avatar.tsx:
  - Shows initials in a colored circle if no image. Color derived from name/pubkey hash.
  - Sizes: 'xs' (24px), 'sm' (32px), 'md' (40px), 'lg' (56px)
  - Optional status dot (green/red/amber) in bottom-right corner

Badge.tsx:
  - Small pill labels. Variants: 'default', 'success', 'warning', 'error', 'accent'

Modal.tsx:
  - Centered overlay, bg-overlay, framer-motion AnimatePresence fade+scale
  - Close button top-right, click-outside to close

AudioMeter.tsx:
  - Takes audioLevel (0-1) as prop
  - 12 vertical bars in a row, each animates height based on frequency data
  - Active bars: accent color. Inactive: border color.
  - Smooth spring animation on bar heights

RecordingDot.tsx:
  - Small red circle with CSS pulse animation (scale + opacity)
  - Optional label: "REC" in JetBrains Mono

=== PART C: Landing Page (src/components/onboarding/LandingPage.tsx) ===

Build a full-screen landing page with these sections:

HERO SECTION:
  - Background: very subtle gradient mesh (2-3 radial gradients, accent color at 4% opacity)
    creating depth without being garish. Add a CSS noise texture overlay at 3% opacity.
  - Large display text using Syne Bold, 72px desktop / 48px mobile:
    "Record Like a Studio."
    (second line, accent color:) "Own It Like Never Before."
  - Subtext in DM Sans, text-secondary:
    "Vessel captures studio-quality audio and video from anywhere in the world.
     Your recordings go straight to you — no monthly fees, no cloud lock-in."
  - Two CTAs side by side:
    [Create Your Free Studio →]  (primary button, large)
    [Watch a Demo ▶]  (ghost button, opens a modal with a placeholder video embed)
  - Below CTAs: social proof line in small muted text:
    "✓ No credit card  ✓ No subscription  ✓ Works on any device"
  - Bottom of hero: subtle fade into a preview of the Studio UI (a static screenshot mockup
    created with HTML/CSS — a dark panel showing fake video tiles and a control bar)

FEATURES SECTION (3 columns):
  Each feature card: large icon (SVG, accent color), bold title, 2-line description.
  
  🎙️ Studio Quality, Zero Compromise
  "Every participant records directly on their device. We capture what your mic and camera
   actually produce — not a compressed video call."

  ⚡ Instant Delivery
  "Your files appear in your vault the moment recording ends. No processing wait,
   no 'we'll email you when it's ready.' Just your media, right now."

  🔒 Permanently Yours
  "Files aren't stored on our servers. They live on a distributed network you control.
   Delete your account and your recordings are still yours."

HOW IT WORKS (3 steps, horizontal):
  Step 1: "Create your studio" — sign up in 10 seconds, no credit card
  Step 2: "Invite your guests" — share a link, they join instantly (no app download)
  Step 3: "Get your files" — everyone's track downloads separately in studio quality

COMPARISON TABLE:
  | | Vessel | Riverside.fm | Zoom |
  |---|---|---|---|
  | Local recording quality | ✓ Lossless | ✓ Lossless | ✗ Compressed |
  | Monthly cost | Free | $15–$100 | $15–$20 |
  | You own the files | ✓ Always | ✗ Platform-stored | ✗ Platform-stored |
  | No account for guests | ✓ Link only | ✗ Required | ✗ Required |
  | Works offline/spotty wifi | ✓ Records locally | ✓ | ✗ |

FOOTER:
  - Logo + tagline
  - Links: Privacy (simple modal), Terms (simple modal), Twitter/X, GitHub
  - Bottom line: "Built on open protocols. Your media never touches our servers."
  - DO NOT mention Nostr, Blossom, QUIC, or any protocol names.

=== PART D: Responsive ===
- Mobile-first. The landing page must look great on iPhone.
- Hero text scales down gracefully. Feature cards stack to single column.
- CTAs become full-width on mobile.
- Test at 390px width.
